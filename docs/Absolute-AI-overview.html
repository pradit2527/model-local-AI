1. ภาพรวม

3. ความสามารถ

  • หน้าแชท 3 ส่วน: A = ประวัติแชท, ตรงกลาง = แชท, B = ผลลัพธ์ (โค้ด / หน้าจอ / รูป / วิดีโอ) และลากเส้นแบ่งปรับขนาดได้
  • รันผลลัพธ์ทันที แบบ Claude Artifacts รองรับ HTML, React, Python (Pyodide) และ Mermaid
  • Mockup อัตโนมัติ: เสนอไอเดียแล้ว แถบ B จะแสดงหน้าจอตัวอย่างให้เอง
  • ปุ่ม + แนบรูป, PDF, Word, Excel, CSV และอ่านตัวอักษรจากรูป (OCR) ได้ทั้งไทย อังกฤษ และจีน
  • Skills เลือกได้หลายตัว: Coding, Vibe Code, VS Code, Database, Design, System Analysis
  • MCP: filesystem (โฟลเดอร์ workspace) และ DBHub (SQLite, เพิ่ม Postgres/MySQL/SQL Server ได้)
  • Tools: ค้นเว็บ, เปิดอ่าน URL, เครื่องคิดเลข, เวลาปัจจุบัน, สร้างรูป/วิดีโอ และรันคำสั่ง (ต้องกดอนุมัติก่อน)
  • โหมดแม่นยำ: อ้างอิงแหล่งข้อมูลจริง และคำนวณด้วยเครื่องมือแทนการเดา
  • ภาษา: หน้าเว็บมี 5 ภาษา (ไทย/อังกฤษ/จีน/ญี่ปุ่น/เกาหลี) และเลือกภาษาคำตอบได้ 40 ภาษา
  • ธีม: สว่าง/มืด, โลโก้แนว hacker, ลายน้ำ "AI สายดาร์ก", แถบเลื่อนบางแบบ Claude

4. ขั้นตอนที่ทำไปแล้ว

  1. คัดเลือกและดาวน์โหลด โมเดลกับ datasets ของ UnfilteredAI จาก Hugging Face ตรวจไฟล์ด้วย sha256
  2. ติดตั้ง Ollama บน A01 ที่พอร์ต 11500 ซึ่งไม่ชนกับ NVIDIA AI Router ที่ใช้ 11434/11435 แล้วเชื่อมจากโน้ตบุ๊กผ่าน SSH tunnel โดยไม่ต้องเปิดไฟร์วอลล์
  3. สร้าง Bridge และหน้าแชท รวมระบบเลือกโมเดล, Skills, MCP, ค้นเว็บ, tools, ประวัติแชท และแผงผลลัพธ์
  4. วัดผลตั้งต้น ของ dan-l3-r1-8b: GSM8K 76.0, ARC 71.0, ThaiExam 18.0, HumanEval 42.7
  5. เตรียมข้อมูลเทรน รวมราว 15,000 ตัวอย่าง: โค้ด, การเรียก tool (Hermes), คณิต, ไทย, Aya หลายภาษา, งาน design/system analysis และตัวตน "Absolute AI"
  6. ย้ายงาน PyTorch ไป WSL2 เพราะ Smart App Control บน A01 บล็อก DLL ของ CUDA ฝั่ง Windows ทั้งการเทรนและ ComfyUI จึงรันใน Ubuntu
  7. ติดตั้งระบบสื่อ ได้แก่ Gemma4, Typhoon, Qwen3.6 Coding, ComfyUI + FLUX + Wan2.2 เสร็จแล้ว
  8. ตั้งค่า VS Code (Continue) ให้ชี้ไปที่โมเดลบน A01 พร้อมสคริปต์ติดตั้ง
